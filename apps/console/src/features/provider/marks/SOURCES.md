# Provider marks

The marks of the sign-in providers the console knows, each drawn in one colour, that of
the text around it: `provider-mark.tsx` shows a file through a mask, so whatever a file
is coloured with is not seen. They are trademarks of their owners and are shown to name
the provider a button or a row is of, and for nothing else.
